
# Умный кредитный кабинет предпринимателя
Цифровой кредитный конвейер для малого и микробизнеса: клиент проходит путь от потребности в деньгах до результата по заявке, банк ведёт тот же объект в очереди обработки.
Прототип для кейса Changellenge × Альфа-Банк. Все данные синтетические, внешние проверки — локальные симуляторы. Платные API не используются.
## Что умеет MVP
- Подбор продукта от цели бизнеса (оборот, кассовый разрыв, оборудование).
- Личный кабинет клиента со статусом, журналом и следующим шагом.
- Конвейер: комплектность → БКИ/ЕГРЮЛ/ФНС → скоринг → кредитное решение.
- Решение не сводится к баллу: возможны одобрение, оферта с изменениями, запрос сведений, отказ.
- Новостная лента, которая меняется с ролью, отраслью и статусом заявки.
- Кабинет аналитика/андеррайтера с ручным решением.
## Архитектура

Четыре контейнера: PostgreSQL, FastAPI, отдельный ML-сервис и nginx+SPA. Для логов используйте `docker compose logs -f api`. Подробности — в `docs/architecture.md` и `docs/ml.md`. Схема состояний — `docs/state-diagram.md`. Модель данных — `docs/data-model.md`.
## Требования к окружению
- Docker и Docker Compose
- Либо Python 3.12 и Node 20 для локальной разработки
Зафиксированные версии: `backend/requirements.txt`, `frontend/package-lock.json`.
Проверяемая версия для жюри — Docker Compose с PostgreSQL. SQLite остаётся только для разработки, если Docker ещё не установлен.

### Переменные окружения
См. `.env.example`. Для compose заданы в `docker-compose.yml`.
| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | SQLAlchemy URL |
| `JWT_SECRET` | секрет токена |
| `PIPELINE_STEP_DELAY_SEC` | пауза между этапами конвейера (для демо) |
| `CORS_ORIGINS` | разрешённые origin |
| `SEED_ON_START` | загрузка демо-данных |
| `ML_SERVICE_URL` | адрес ML-сервиса внутри Compose |
| `ML_TRAINING_DATA` | путь к историческому CSV |
| `ML_ARTIFACT_PATH` | путь к joblib-артефакту |
| `ML_DATE_COLUMN` | колонка даты для temporal validation |
| `ML_DRIFT_THRESHOLD` | порог drift monitoring |

## Сценарий проверки за 5 минут
1. Войти как Мария.
2. Открыть «Лента» — новости про пищевое производство.
3. Создать заявку на оборотный кредит ~1,5 млн ₽.
4. Наблюдать смену статусов на карточке.
5. Принять оферту и подписать документы.
6. Выйти, войти как Павел — лента другая, крупная заявка уходит в отказ или уточнение.
7. Войти как аналитик и открыть очередь.
Полный чеклист: `docs/test-scenarios.md`. Коллекция запросов: `postman/credit-cabinet.postman_collection.json`.
## Локальная разработка без Docker UI
```bash
# API. Без DATABASE_URL используется SQLite-файл backend/cabinet.db
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
# Web
cd frontend
npm install
npm run dev
```
Тесты скоринга и персонализации ленты:
```bash
cd backend && PYTHONPATH=. pytest -q
```
## Допущения
- Подписание и выдача денег смоделированы кнопками внутри продукта.
- БКИ, ЕГРЮЛ и ФНС отвечают фиксированными профилями по ИНН.
- Скоринг включает прозрачную rule-based модель и дополнительный ML-сигнал на `scikit-learn`.
- ML-модель вынесена в отдельный сервис, сохраняется через joblib и поддерживает обучение из CSV исторических данных; без CSV используется только синтетический fallback.
- LLM не используется: для проверяемого сценария достаточно локального ML без внешних API.
- Подробности ML-компонента: `docs/ml.md`.

## Предупреждение
Проект предназначен для демонстрации на хакатоне. Все пользователи, пароли, компании и финансовые показатели синтетические. Не используйте текущие секреты и demo123 в production.
