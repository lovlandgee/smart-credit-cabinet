# Модель данных
## Сущности
- `users` — представитель клиента или сотрудник банка.
- `companies` — синтетический профиль ММБ (реквизиты, финансы, ОКВЭД).
- `products` — кредитные продукты и продуктовые лимиты.
- `applications` — заявка как сквозной объект конвейера.
- `application_events` — журнал движения.
- `news_items` — карточки ленты с правилами персонализации.
## Заявка
Ключевые поля: сумма и срок запроса, цель, статус, балл, риск-сегмент, JSON скоринга, JSON обогащения, оферта, код решения, подпись документов.
## Статусы
`submitted → intake → enrichment → scoring → decision → offered | need_info | rejected → documents → disbursement → completed`
Альтернативы: `cancelled` с клиентской стороны, ручное решение банка из очереди.
