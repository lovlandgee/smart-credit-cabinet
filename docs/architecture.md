# Архитектура

## Компоненты

- `frontend` — React + Vite SPA, раздаётся Nginx.
- `backend` — FastAPI API и асинхронный pipeline обработки заявки.
- PostgreSQL — постоянное хранение пользователей, компаний, заявок, событий и результатов оценки.
- Локальные интеграции — синтетические симуляторы БКИ, ЕГРЮЛ/ЕГРИП и ФНС.
- ML-модуль — воспроизводимая `scikit-learn` LogisticRegression на синтетических данных.

## Поток заявки

1. Клиент создаёт заявку через `POST /api/applications`.
2. Background task запускает проверку комплектности.
3. Pipeline получает синтетическое обогащение из локальных интеграций.
4. Rule-based scoring рассчитывает объяснимые факторы.
5. ML-модель рассчитывает вероятность дефолта и ML-оценку риска.
6. Итоговый балл объединяет прозрачный скоринг на 70% и ML-сигнал на 30%.
7. Decision engine учитывает балл, продукт, сумму, срок и лимиты.
8. Все этапы записываются в журнал заявки.

## Запуск

```bash
docker compose up --pull always --build
```

- Web: `http://localhost:8080`
- API через Nginx: `http://localhost:8080/api`
- Swagger: `http://localhost:8080/docs`
- Health: `http://localhost:8080/health`

## Ограничения

ML-модель обучается при импорте на синтетическом наборе с фиксированным seed. Она нужна для демонстрации ML-пайплайна и объяснения архитектуры, но не является валидированной кредитной моделью и не должна применяться к реальным решениям без качественных размеченных данных, валидации, мониторинга и аудита.
